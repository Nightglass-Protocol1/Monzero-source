Monzero for Linux (64-bit PC)
=============================

Start the wallet
  Open this folder in a terminal and run:

      ./monzero-wallet-gui

  To add "Monzero" to your applications menu, run  ./install-desktop-entry.sh  once. It
  only writes a menu entry and icon that point at this folder; run it again if you move
  the folder.

Keep the files together
  The wallet starts monzerod and the helper programs in monzero-dex/ and monzero-light/
  from this folder. Do not move them apart or rename them.

Trading on the DEX
  Open "Exchange" in the wallet's menu: XMZ against ETH, BNB and SOL with a price chart,
  order book and buy/sell, no browser needed. Choose a trading password the first time.
  Send the coin you pay with to the trade account shown under Funds. Read RELEASE_NOTES.md
  first. The DEX page https://monzero.org/dex/ also still works with this wallet.

Your own look
  Settings > Layout > Appearance: colour sets, your own colours and a picture on the wallet card.

Node and command-line tools
  monzerod, monzero-wallet-cli and monzero-wallet-rpc are the same as in the command-line
  package. See README.md and README-SYSTEMD.md.

Check what you downloaded
  sha256sum -c SHA256SUMS      (inside this folder)
  The archive's own SHA-256 is published in the signed release file on
  https://monzero.org/download/.

Needs: a 64-bit Intel or AMD PC and glibc 2.35 or newer (Ubuntu 22.04, Debian 12 or later).
The wallet window uses X11; on a Wayland desktop it runs through XWayland, which desktops
start for you.
