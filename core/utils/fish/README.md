## Fish shell completions for Monzero

This folder has basic Fish completions for `monzerod`, `monzero-wallet-cli`,
and `monzero-wallet-rpc`. To use them, put those files (or symlink them) inside
`~/.config/fish/completions/` or wherever your Fish completion files are (see
[the Fish completion documentation](https://fishshell.com/docs/current/completions.html#where-to-put-completions)).
