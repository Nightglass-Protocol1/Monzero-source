1. Check the signature

The hash list is signed with the Monzero release key. Its fingerprint, also published at monzero.org/download:

4C37 C618 789F 86D8 1FEF  28DF 390A EFB7 35F2 70D6
gpg --verify SHA256SUMS.asc SHA256SUMS

First import the public key once: curl -s https://monzero.org/releases/monzero-release-public.asc | gpg --import

You should see Good signature from "Monzero Release <security@monzero.org>" and Primary key fingerprint: 4C37 C618 789F 86D8 1FEF 28DF 390A EFB7 35F2 70D6. gpg also names the key that made the signature, 562B A9C3 A713 E4E0 5A1B 24F2 5794 0142 228A 8336: that is the signing subkey of the same release key. The warning "This key is not certified with a trusted signature" is normal for a key you have not personally certified; what matters is the primary fingerprint above.

2. Check the files

Download the files this site serves and compare them with the signed list:

for f in index.html style.css app.js app.js.LICENSE.txt monero.worker.js; do curl -sO @@ORIGIN@@/$f; done
sha256sum -c SHA256SUMS

Every line must say OK. Anything else means the files differ from the release: do not enter your recovery words, and tell the Monzero team.

3. Build it yourself (optional)

The wallet can be rebuilt from the source with web-wallet/build.sh and web-wallet/app/build.sh; compare the result with the signed list above. (Byte-for-byte reproducible builds are being checked; until that is confirmed, rely on the signature.)

Staying safe

  • Only use the wallet at @@ORIGIN@@.
  • Never type your 25 recovery words into any other website, chat or email. Nobody from Monzero will ever ask for them.
  • For large amounts, use the desktop or Android wallet.
