    Code and documentation

    CPU mining measurements

    Share reproducible RandomX measurements with hardware, software and power-measurement details. Submitted measurements need review before appearing in the catalog.

    Benchmark catalog and submission guide

    Security reports

    Use the coordinated disclosure instructions for vulnerabilities. Avoid publishing sensitive exploit details in a public issue or group chat.

    Security reporting instructions

    GitHub issues and Telegram messages may be public. Never include wallet seeds, private keys, passwords or unredacted sensitive logs.

    Planned community features

    Proposal voting, bounty submissions and optional achievement badges are planned. Submissions and voting are not open here yet. These features require moderation, authentication, abuse controls and auditable records before opening. Community polls will provide non-binding feedback; they will not change blockchain rules.

    No funded bounty rewards are advertised on this page. Reward funding, acceptance criteria and review processes must be published before a bounty opens.
