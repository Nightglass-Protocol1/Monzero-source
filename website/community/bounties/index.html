Paid · 1,000 XMZ

Single network hashrate on the pool and website

On 26 October 2026, @nlman777 on Telegram reported that the pool page listed a pool hash rate and a network hash rate side by side. Miners read them as two network figures that disagreed. The same report came with the fix: show one overall network hash rate, made up of pool and solo miners. That fix went live on pool.monzero.org, the homepage and the network stats page on 28 October 2026.

Before starting a task

Read the acceptance criteria and submission instructions, then contact the listed maintainer through the discussion link. Check whether work is already underway and confirm reward terms. Evidence links and their dates help you assess the claim; they do not independently prove that funds remain available.

Completed means work was accepted. Reported paid is a separate funding state and requires separate payment evidence.
