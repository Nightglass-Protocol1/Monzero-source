XMZ PAYMENTS

Create a payment request.

Enter your public receiving address to make a monzero: link and QR code that Monzero wallets can scan. Everything happens in this browser tab: nothing is sent to a server or saved.

Only ever enter a public address. This page never asks for a seed phrase, private key or wallet password, and it cannot send or receive funds.

Request details

Leave the amount empty to let the payer choose. Amounts use up to 11 decimal places.

The name and description are shown in the payer’s wallet and may be saved there as a note. They are not written to the blockchain, and you will not see them when the payment arrives. To tell payments apart, give each payer a different subaddress or an integrated address from your wallet.

Payment request

Enter a valid address to create a request.

Before you share a request

  • Check the address against your wallet’s receive screen. If you copied it from somewhere else, make sure it was not changed.
  • An amount in the request is a suggestion. The payer’s wallet lets them edit it before sending.
  • A test or stage network address only works with that network’s wallets. Don’t use one to request real XMZ.
  • Payments are private. Only your wallet, using your keys, can confirm that you received one; this website cannot.

The link format is the one the Monzero wallet creates and reads: monzero:<address>?tx_amount=…&recipient_name=…&tx_description=…. Developers can read more in the merchant integration guide.
