Add a project

To suggest a pool, wallet, explorer, library, merchant or guide, open an issue on GitHub with its name, category, official URL, who runs it, and a short description. A maintainer checks that the service works and is what it claims to be before adding it, and records the date it was checked. Entries that stop working are removed.

Exchanges are tracked separately on the exchanges page, which needs a dated verification for each live market. No merchants have been reviewed yet.
