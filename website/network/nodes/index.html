How these numbers are made

Collectors next to the public nodes node.monzero.org (EU) and node2.monzero.org (US) read each node's own peer list and open connections. Each looks up every public IP in an offline IP-to-country database and replaces the address with a one-way tag that changes every day, using a key only the two nodes share. The website counts a node seen from both places once and publishes only per-country totals. It never receives IP addresses, and Tor and I2P peers are not counted.

  • Accepting connections: nodes the public node completed a handshake with in the last 24 hours.
  • Connected now: open connections at collection time, including nodes behind firewalls.
  • Observed: distinct addresses in either group.

These are approximate. A country lookup can be wrong (VPNs, hosting providers, outdated database), one node can use several addresses, and two vantage points still do not see every node. This is not a count of users or miners.
