Mining pool

Prefer sharing block rewards? Mine with others at pool.monzero.org: the pool reported PPLNS, a 1% fee, payouts from 1 XMZ and 60 confirmations when checked on 19 October 2026. Check the pool for current terms and payout status. Point XMRig at port 3333 (CPUs and laptops) or 5555 (servers and rigs), with your Monzero address as the login:

xmrig -o pool.monzero.org:3333 -u YOUR_MONZERO_ADDRESS -p rig1 -a rx/0

  1. 1
    Start the node./start-monzerod.sh
  2. 2
    Start the separate miner./start-monzero-miner.sh YOUR_ADDRESS 1
  3. 3
    Open the wallet when needed./start-monzero-wallet-cli.sh

Windows mining

Mine XMZ on Windows.

Use the Windows command-line package. Extract the complete ZIP before running anything; do not launch files from inside the ZIP.

  1. 1
    Start and synchronise the node

    Double-click start-node.bat, allow the Windows Firewall prompt, and leave the window open. The launcher connects to node.monzero.org:6174 and the local RPC listens on 127.0.0.1:6175.

  2. 2
    Create a fresh wallet

    Run start-wallet-cli.bat, create a Monzero-only wallet, and record its recovery seed offline. Never reuse a Monero wallet or seed.

  3. 3
    Start CPU mining

    Open Command Prompt in the extracted folder and run start-mining.bat YOUR_MONZERO_ADDRESS 2. Replace the address and choose the number of CPU threads you want to use.

  4. 4
    Check rewards and stop

    Run balance in the wallet to see mined rewards; they unlock after 60 blocks. Run stop-mining.bat when you want to stop mining.

Questions

Before you begin.

Why is my mining balance still zero?

With solo mining, you receive a reward only when your machine finds a block. A found reward remains locked for 60 blocks. Pool mining shares rewards between participants, subject to the pool’s payout rules and network conditions.

Is Monzero the same network as Monero?

No. Monzero is an independent experimental chain with a different genesis block, network ID, ports, address prefixes, ticker, and monetary policy.

Can I reuse my existing seed?

No. Create a new wallet and seed exclusively for Monzero. Reusing keys across forks can seriously damage privacy.

Is this a stable release?

Yes. Monzero v1.0.0 is the first stable release. It continues the pre10–pre16 chain (no reset) and switches difficulty to LWMA at block 21,000, so anyone running their own node must upgrade before then. It has not yet been independently audited; report problems to security@monzero.org.
