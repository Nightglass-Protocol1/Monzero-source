Older releases

Every earlier package stays here, with its SHA-256 checksum, for reference, verification and going back a version. Use the current release unless you have a reason not to: older versions lack later fixes (for example SOL and USDT withdrawals before v1.3.6 / Android 1.1.13). Check the SHA-256 of any download before running it.
