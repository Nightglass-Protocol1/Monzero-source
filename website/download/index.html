Monzero v1.0.0 · stable release

Download Monzero

v1.0.0 network upgrade. Since block 21,000 (31 October) the network uses LWMA difficulty (hard fork 17), continuing the existing chain. Nodes and wallets older than v1.0.0 stop syncing at that block; update to the packages below. Read the upgrade guide and current status.

Stable v1.0.0 graphical wallet and command-line build for Linux x86-64, plus full source. Also available as a web wallet and an Android app below. Stable packages include the protocol whitepaper, release notes and the upgrade guide.

Monzero Web Wallet · in your browser · nothing to install

Web wallet

wallet.monzero.org runs a full Monzero wallet in your browser. Your keys and 25 recovery words never leave your device: the wallet is Monzero's own wallet code running locally, and the site only relays blockchain data from the Monzero node. Create or restore a wallet, receive with a QR code and send with a confirmation screen. It locks itself after 10 minutes without use.

Check before you trust it: every release is signed with the Monzero release key (fingerprint 4C37 C618 789F 86D8 1FEF 28DF 390A EFB7 35F2 70D6). The wallet's verification page lists the file hashes and shows how to check them. For large amounts, use the desktop or Android wallet.

Want to try it first with test coins? Use the testnet web wallet.

Monzero for Android · Wallet 1.0.1 · Miner 1.0.0 · direct download

Android wallet and miner

Monzero Wallet sends and receives XMZ from your phone. Your keys stay on the phone, and the wallet syncs through node.monzero.org or a node you choose. It is based on the open-source Monerujo wallet. Monzero Miner mines XMZ with your phone's processor through the Monzero pool, using XMRig.

Wallet 1.0.1 (30 October): fixes the wallet closing straight after you open it. With a VPN on, 1.0.0 could start without a node and then close; if the node cannot be reached, the app now says why instead of closing silently. Install it over 1.0.0: your wallets stay.

Google Play and F-Droid are coming. Until then, install the APK from this page. Most phones need the arm64 wallet; the universal build also runs on x86-64 devices and emulators.

Install

  1. Download the APK on your phone and open it.
  2. When Android asks, allow your browser or file manager to install unknown apps.
  3. Optional: check the SHA-256 shown here, and confirm that Android reports the signing certificate below.

Signing certificate SHA-256 5D:F1:7D:CA:11:0F:22:D7:00:E5:AB:50:C5:0B:A9:D2:2C:BE:D6:5C:FA:6F:AD:78:6B:FF:0B:2C:AE:C8:CE:FD

Phone mining earns little and makes the phone warm. By default the miner runs only while charging, pauses when the battery reaches 40 °C and uses half the cores. XMRig's standard 1% developer donation is kept. Early release, not independently audited: start with small amounts and report issues to security@monzero.org.
