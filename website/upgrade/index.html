NETWORK UPGRADE

Upgrade to v1.0.0 before block 21,000

At block 21,000 the network switches to a faster difficulty rule (LWMA). Nodes and wallets need Monzero v1.0.0 to keep following the chain. It is the same chain: no reset, no new coins, and every balance stays where it is.

Download v1.0.0

Who needs to do what

You useAction before block 21,000
The GUI wallet (Windows)Update to the v1.0.0 GUI. Your wallet file and seed stay the same.
The CLI wallet or wallet RPCUpdate to the v1.0.0 archive (it contains monzerod, the CLI wallet and wallet RPC).
Your own node (monzerod), including solo miningUpdate to v1.0.0 and keep the computer clock synchronized (NTP): from block 21,000 a block may be at most 6 minutes ahead of a node's clock.
A pool, explorer or exchangeUpdate every node you run.
Mining on a pool (for example pool.monzero.org)Nothing. Your payout address and balance do not change.

Check your version

  • GUI wallet: open Settings → Info. The line Embedded Monzero version should start with 1.0.0.
  • Command line: run monzerod --version and monzero-wallet-cli --version. v1.0.0 prints a version starting with 1.0.0; the older pre16 release printed 0.18.5.1.
  • Your node: the RPC call hard_fork_info should show "voting": 17 and "earliest_height": 21000.

If you miss it

Your coins are safe. An old wallet stops syncing at block 21,000 and shows Unexpected hard fork version v17. Install v1.0.0 and open the same wallet file (or restore the same seed); it syncs normally. An old node stops following the main chain at that block; update it and it continues from where it stopped.

Verify your download

The release file listing every download's SHA-256 is signed with the Monzero release key, fingerprint 4C37 C618 789F 86D8 1FEF 28DF 390A EFB7 35F2 70D6. Check the file's SHA-256 before you install, and download only from monzero.org.

Release notes · Whitepaper section 4.4 (the new difficulty rule) · Problems: Telegram or security@monzero.org for anything security-related.

Nobody from Monzero will ever ask for your seed, keys or wallet password to "help with the upgrade". Anyone who does is a scammer.
