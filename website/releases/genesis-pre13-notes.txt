CHANGES SINCE PRE12

- Fixed a peer synchronization stall caused by an incoming object request
  overwriting the timer used to track an outstanding synchronization request.
- Added a regression test for preservation of pending synchronization state.
- Removed circular pool initialization undefined behaviour.
- Hardened cancelled wallet creation and release/CI package checks.
- Disabled accidental host ICU detection in the pinned Boost depends build.
- Consensus identity and chain rules are unchanged from pre10 through pre12.
- GUI package revision 2 starts its managed local daemon with synchronization
  enabled and selects the local RPC endpoint automatically. New users do not
  need to enter 127.0.0.1 or configure a node address.

TEST STATUS AND LIMITATIONS

All 1,305 unit tests passed. The exact Linux archive passed clean-container
startup, three-node propagation/reorganization/transfer testing, and wallet
creation/restoration testing. The exact Windows CLI archive passed native
daemon startup, local RPC, and clean shutdown testing. The Windows GUI package
passed archive, manifest, PE mitigation, subsystem, and noninteractive native
startup checks; interactive wallet workflows remain pending.

Independent binary reproduction, release signing, sustained live-network
observation, interactive Windows GUI testing, and an independent security
review remain outstanding. Keep the prior verified installation available for
rollback.
