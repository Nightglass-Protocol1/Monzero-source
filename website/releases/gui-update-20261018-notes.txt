Monzero v1.0.0 Windows GUI stable update — 18 October 2026

Published as a stable GUI update with project-owner approval. Native Windows validation remains pending; see the validation section below.
Open start-wallet-gui.bat. In local-node mode, the wallet checks for an existing node and starts it automatically when needed. Wait for synchronization.
Open Mining / tools, select CPU threads, then Start mining. Stop mining explicitly when finished: a local node can continue mining after the GUI closes. Solo rewards require finding a block and unlock after 60 blocks. The page reports the actual reward address and live hashrate.

Changes: teal theme and supplied XMZ artwork; bounded local-node startup checks; explicit asynchronous mining controls; mining-status refresh across pages; bundled outline fonts.

Validation: QML behavior tests and Windows GUI execution under Wine with an isolated native testnet daemon. Native Windows 10/11 validation is still required. Wine could not initialize the Windows daemon/shared ring database.
The core executables are unchanged files from the verified v1.0.0 archive. No DEX development code is included.
