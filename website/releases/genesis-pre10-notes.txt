CHANGES SINCE PRE9

- Establishes a fresh mainnet identity with a new network UUID, genesis nonce,
  and derived genesis block hash.
- Includes the branded GUI artwork and the GUI issuance workflow developed
  after pre9.
- Retains the existing ports, address prefixes, premine-free genesis
  transaction, XMZ currency rules, and inactive public asset hard fork.

MIGRATION

Pre10 is intentionally incompatible with pre9 chain data. Stop pre9 before
installing pre10 and move the old mainnet blockchain directory aside. Do not
copy an LMDB database from pre9 into a pre10 data directory. Wallet keys and
seeds do not need conversion, but creating a fresh Monzero-only wallet is
recommended for the new network. Never reuse a Monero or other CryptoNote seed.

TEST STATUS AND LIMITATIONS

The pre10 core source passed 1,298 unit tests, 18 RPC functional tests, and the
complete 175-test core replay with no failures. Release checksum and structural
verification passed for the Linux, Windows CLI, core source, and GUI source
archives; the GUI archive's internal checksum manifest also passes. The
Linux requires GLIBC 2.42 or newer. The artifacts are unsigned and have not
been independently reproduced or audited.
Native Windows execution, sustained sanitizer fuzzing, and broader independent
network testing remain outstanding. Windows may show an unknown-publisher
warning.
