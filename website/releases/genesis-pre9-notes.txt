CHANGES SINCE PRE8

- Uses defined multiplication for cryptographic carry normalization.
- Corrects enum varint serialization without changing the established bytes.
- Adds modern view-tagged mined-reward ownership coverage to the source tree.
- Defaults new GUI wallets to Monzero/wallets while continuing to discover
  existing wallets in the legacy Monero/wallets directory.

TEST STATUS

At the publisher's direction, no test suite, archive verifier, native startup,
wallet lifecycle, network, or platform smoke test was run to qualify these
exact pre9 artifacts. Compilation and checksum generation are not test
evidence. Earlier pre8 results do not qualify pre9.

LIMITATIONS

The artifacts are unsigned and have not been independently reproduced or
audited. The public network has limited independent infrastructure and hash
power. Windows may show an unknown-publisher warning. Never reuse a Monero or
other CryptoNote seed, keys, wallet, or data directory with Monzero.
