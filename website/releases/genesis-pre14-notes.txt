CHANGES SINCE PRE13

- Added isolated, fixture-only DEX-lab preparation tooling (utils/dex-lab/)
  for a separate, air-gapped-from-production VM. It ships no live adapters,
  no atomic settlement, and no funds verification, and is not wired into
  any release package or public network path.
- Closed a release-verification gap where a Windows GUI archive could ship
  binaries built against a different core commit than its manifest
  declared.
- Added .gitignore patterns for wallet key and backup files as a backstop
  against accidental commits of wallet material.
- Consensus identity and chain rules are unchanged from pre10 through pre13.
  No file under src/ changed since pre13.
- The graphical wallet in this package is built from an older, compatible
  monzero-gui source commit, not the GUI project's current development
  tip, which has diverged onto unmerged asset transfer/burn UI work this
  core commit does not yet implement. Real-money DEX trading, cross-chain
  settlement, and native asset transfer/burn are unavailable in this
  package.

TEST STATUS AND LIMITATIONS

All 1,305 unit tests and all 20 ctest suites passed on the local Linux
build. The Linux CLI archive was built with the ordinary system toolchain,
not the pinned reproducible-build/depends environment used for prior
published candidates, and has not passed strict package verification or
the digest-pinned container smoke test. The Windows CLI and GUI archives
were cross-compiled in the pinned build environments and passed their
package, manifest, checksum, PE-mitigation, and (for the GUI) subsystem
checks, but neither has been run on a native Windows host. The RPC
functional-test suite did not run on this build host (missing Python
dependencies, not a code regression).

Independent binary reproduction, release signing, native Windows testing,
sustained live-network observation, and an independent security review
remain outstanding. Keep the prior verified installation available for
rollback.
